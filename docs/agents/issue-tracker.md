# Issue tracker: GitHub, in the front repository

This repository has no tracker of its own. Backend work is tracked in the GitHub Issues of `abner-augusto/UFCIM-FRONT3D`, together with the front's.

- Pass `-R abner-augusto/UFCIM-FRONT3D` to every `gh issue` command run from this clone (`gh` otherwise infers this repository).
- Issue shape, labels, public-repository rules and skill operations are defined in the front repository's `docs/agents/issue-tracker.md` (a sibling clone at `../UFCIM-FRONT3D`). Read it before creating, triaging or closing an issue.
